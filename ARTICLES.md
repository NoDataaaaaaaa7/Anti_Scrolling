# Anti Scrolling — публикация статей

Контент приложения хранится локально в `src/data/topics.json`. Supabase для статей не нужен.

## Расписание

В архиве подготовлено по три статьи для каждого из пяти разделов: философия, психология, экономика, математика и литература. Даты публикации: 3, 4 и 5 ноября 2026 года. Приложение выбирает статью по локальной дате устройства и выбранной категории.

## Как добавить следующую статью

1. Откройте `src/data/topics.json` на GitHub.
2. Добавьте новый объект внутрь массива (после последнего объекта поставьте запятую).
3. Укажите уникальный `id`, дату `publish_date` в формате `YYYY-MM-DD`, одну из категорий и содержимое.
4. Сохраните изменения в ветку `main`. Cloudflare Pages автоматически соберёт сайт.

Допустимые категории: `philosophy`, `psychology`, `economics`, `mathematics`, `literature`.

## Структура статьи

Каждая статья содержит `title`, `tagline`, `intro`, `image_url` и `content`. В `content` обязательны массивы `sections`, `timeline`, `facts`, `definitions` и объект `quote`. В разделе `sections` желательно делать 4–6 смысловых частей с содержательными абзацами.

## Важно

- На каждую дату и категорию должна приходиться не более чем одна статья: поиск выбирает первую подходящую запись.
- Если для сегодняшней даты статьи нет, приложение покажет сообщение, что публикация ещё не состоялась.
- Для публикации заранее добавляйте статьи с будущими датами.
- Даты определяются по локальному времени устройства читателя.
- Не добавляйте секретные ключи и `.env` в публичный репозиторий.
